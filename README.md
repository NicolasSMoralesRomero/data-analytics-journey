## 🧠 Analytical Principles

1. **Audit Before Analyzing.** A metric calculated on dirty data is a liability, not an insight.
2. **Commits Document Thinking.** Version control is a technical journal. Commits communicate reasoning and business impact, not just file changes.
3. **Context Over Averages.** The average often lies in operations. Median, P90, and distribution curves tell the real story of SLA performance.
4. **Insight Framework.** *Finding → Evidence → Impact → Action.* Observations without evidence are opinions; evidence without action is noise.
